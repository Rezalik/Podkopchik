# AX6000: Emergency Retirement And Cleanup

On 2026-11-08 the operator explicitly requested removal of the separate
emergency recovery mechanism and old backups from Xiaomi AX6000. Only
`ssh openwrt` was used; `openwrt2` and GitHub main were not touched.

## Safe Retirement

The active repair generation depended on its emergency watcher. Stopping that
watcher first would trigger the Native fail-closed path. Instead, the existing
ordinary Apply validated and confirmed `native_recovery_policy=transactional`.
Generation `f869db15664b21d81ab87f1391c80228` was confirmed at epoch 1794132715,
with no pending transaction and `repair=false`.

The independent emergency service was then stopped and disabled, its leftover
one-digit `K9` stop symlink was checked and removed, and
`/etc/podkopchik-native-emergency` was deleted. No emergency or rescue-Xray
instance remains. Dormant application support code is retained, not armed.
Ordinary validation and compensation for a failed/unconfirmed Apply remain
part of Native; this is not removal of all application safety checks.

## Cleanup Scope

Fifty-one checked top-level entries were removed: old Stage 4/r7/Xray/Universal
test backups under `/root`, the temporary LuCI update/recovery archives, a
retired wireless backup, obsolete diagnostic/staging files in `/tmp`, and the
retired emergency capsule. Before deletion, the operation checked the current
confirmed generation, disabled service, absence of rescue rules, exact path
allowlist, startup/cron references, process arguments, open descriptors and
mount boundaries. No user files outside this list were removed.

Flash free space increased from 17,048 KiB at initial inventory to 41,260 KiB
after cleanup, about 16.6 -> 40.3 MiB. The deletion operation itself freed
23,948 KiB flash. Tmpfs usage fell from about 32 MiB to 1.6 MiB.
The approximately 57 MB of removed logical file contents span both filesystems
and must not be described as that much physical flash recovered.

Kept: current AWG profiles, UCI, Native executable, current/previous generation
and code state, legacy state referenced by the engine, synthetic namespace and
watermark history, firewall/policy ownership records, and the bounded observer.
The allocator was not rewound. Existing Mac backups were not deleted, and no
new secret configuration was transferred to the Mac for this operation.
