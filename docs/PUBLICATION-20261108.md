# Копия Для GitHub: 8 Ноября 2026

Текущая разработка публикуется в `feature/universal-routing-engine` репозитория
`Rezalik/Podkopchik`. Это копия исходников и документации, не архив домашнего
роутера, не образ OpenWrt и не стабильный подписанный релиз.

## Состав

- Universal Routing Engine, Native DNS, независимый AWG и адаптер Xray/VLESS.
- Выборочные defaults, согласованные LuCI/Native-статусы, русский LMO.
- Наблюдатель, учитывающий отсутствие добровольно отключённой аварийной капсулы.
- Тесты и локальные инструменты сборки/контролируемой установки.
- Полностью русский README и [инструкция пользователя](GUIDE-RU.md).
- Обезличенные датированные отчёты о физической проверке Xiaomi AX6000.

Локальная история разработки сохраняется в той же feature-ветке. Старый план
публикации отдельного снимка `codex/native-rc-ax6000-20261108` больше не актуален.
Код `main` не обновляется и force push не используется. Пакеты будущих обновлений
выпускаются отдельными prerelease `native-rc-*`:
[локальная разработка и выпуск](LOCAL-RELEASE-WORKFLOW.md).

## Что Не Включено

Не включаются `.router-backups/`, `.build/`, `tests/.tmp.*`, `.DS_Store`,
пользовательские AWG `.conf`, рабочие VLESS URI, пароли, токены и сырые
захваты/журналы клиентов. Файл `.DS_Store` на компьютере не удаляется и не
изменяется. Служебные файлы Git и данные авторизации также не копируются.

Статическая проверка публикационного списка не нашла реальные токены,
известный пароль роутера или несинтетические встроенные AWG/VLESS-секреты.
Искусственные тестовые ключи/UUID проверены отдельно. Это ограниченная
проверка исходников, а не универсальная гарантия обнаружения любого секрета.

## Проверки

Повторный `tools/check-native-local.sh` после подготовки нового обновлятора
завершился с кодом 0: 73 smoke-сценария, 52 PASS, 21 SKIPPED, 0 FAIL.
SKIPPED включает отсутствующие
на Mac OpenWrt/ucode-зависимости и VM-only проверки, а не фиктивные PASS.
Матрица opkg/apk прошла в изолированных моках, без установки на роутер.

Также проверены 14 LuCI JS-ресурсов, shell-синтаксис, JSON-примеры,
gettext/реальный LMO, Markdown-ссылки, блоки команд и `git diff --check`.
Тест документации FakeDNS обновлён под русский README без изменения routing.
Новый полный пакет переупакован с прежним проверенным ARM64-helper:
его исходники и рецепт сборки совпали побайтово; новая компиляция Go не
заявляется. Две независимые упаковки сравниваются побайтово. В VM отдельно
проверены admission архива, 15 недопустимых архивов, SHA256, установка,
компенсация ошибки записи и отказ при pending Apply. Публикация Actions и
обновление через LuCI на физическом Xiaomi в эту локальную проверку не входят.

Физическое подтверждение относится к AX6000 stock / OpenWrt 25.12.6 /
kernel 6.12.112 и описанной AWG-only конфигурации. Полная текущая физическая
QUIC/IPv6/VLESS-приёмка и завершённая 48-часовая стабильность не заявляются.
Во время подготовки копии настройки рабочего роутера не меняются.
